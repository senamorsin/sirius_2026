# Учебный пример ТК-101

`report.docx` и `report.pdf` — один содержательный отчёт на 10 страниц: около 2500 слов
с учётом таблиц. Это вымышленный пример, оформленный как отчёт об испытаниях;
он не является документом куратора или протоколом испытаний реального оборудования.

Каждой странице соответствует раздел: назначение, аппаратная архитектура, фактическая
конфигурация, алгоритмы, измерения, связь, функциональные испытания, эксплуатация,
документация и решение комиссии. Четыре таблицы содержат параметры, результаты опытов,
редакции документов и открытые замечания. Сведения о соседнем ТК-102 позволяют
проверять, различает ли модель объекты с похожими обозначениями.

`checklist.csv` содержит 32 самостоятельных требования. `expected.json` — ожидаемые
статусы для ручного сравнения, не вход для модели. ID в чек-листе обозначают ожидаемые
группы для удобства демонстрации; сами ID модели не передаются.

| Пункты | Ожидание | Основания |
|---|---|---|
| C01–C18 | Соответствует | Питание, контроллер, входы, размеры, блокировки, измерения, связь, журнал, схема |
| N01–N08 | Не соответствует | IP54 вместо IP65; кабель 18 вместо 25 м; останов 140 вместо ≤100 мс; руководство 2 вместо 4; температура до +40 вместо +50 °C; гарантия 12 вместо 24 месяцев; один вместо двух комплектов; масса 46 вместо ≤40 кг |
| U01–U06 | Недостаточно данных | Неизвестны сопротивление изоляции, дата калибровки, номер блока питания, результаты вибрации, шум и подписанный акт |

Особенно проверить N04: в таблице 3 фактически переданное руководство РЭ-ТК101 имеет
редакцию 2. Упоминание требуемой редакции 4 ниже таблицы не означает её фактическую
передачу. Адрес исходной строки DOCX: таблица 3, строка 2. В PDF — страница 9.
Сопротивление защитной цепи 0,08 Ом не подменяет отсутствующее сопротивление изоляции.

Для демонстрации запустите `uv run sirius-proj`, выберите документ и чек-лист,
дождитесь результатов, проверьте цитаты и сохраните XLSX. Экспертная приёмка должна
проводиться отдельно на примере куратора.


## Комплект куратора

Локальные файлы Word в этом каталоге образуют отдельный набор из 23 требований.
Для запуска нужны «Отчет о НИР учебный.docx» и пустой «Чек-лист.docx».
«Заполненный чек-лист.docx» служит эталоном для ручной сверки.
Рекомендации и эталон не передаются в модель. Результаты проверки и команды
описаны в [протоколе](../docs/VALIDATION.md).
