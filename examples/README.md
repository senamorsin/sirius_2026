# Учебные данные

Синтетический отчёт в двух форматах и 12 требований: четыре соответствия, четыре явных противоречия, четыре случая недостатка данных.
Эталон: expected.json. Пересоздание: uv run python scripts/create_examples.py.
Это демонстрационный набор, он не измеряет качество на реальных отчётах подрядчиков.
