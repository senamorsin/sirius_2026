# Приёмка на примере куратора

Основная приёмка — запуск приложения с документом и чек-листом, предоставленными
куратором. Эти материалы пока не получены, такая приёмка не проводилась.

1. Запустить `uv run sirius-proj`, дождаться подготовки компонентов.
2. Выбрать документ куратора и его CSV-чек-лист; выполнить проверку.
3. Сверить каждый статус с документом, открыть цитаты и проверить их адреса.
4. Проверить русские пояснения, числовые значения, редакции и строки таблиц.
5. Экспортировать XLSX и сверить результаты с окном; повторить для другого формата,
   если куратор предоставил оба формата одного документа.
6. Зафиксировать версию приложения, оборудование, время, расхождения и решение куратора.

`examples/` содержит отдельный учебный пример для демонстрации. Его ожидаемые ответы
не являются результатами приёмки на материалах куратора. Старые измерения на
12 пунктах и инструменты их получения удалены как материалы разработки.

Для регрессионной проверки кода сохранены `uv run pytest -q` и
`uv run ruff check src tests`. Они проверяют поведение программы и не заменяют
экспертную оценку правильности выводов модели.

В текущем учебном прогоне остаются ошибки модели: смешение прошивки и редакции
документа, ошибочные выводы при отсутствии измерений и неподтверждённые цитаты
в отдельных пунктах; ошибочное пояснение возможно и при правильном статусе. Проверка источников подтверждает подлинность текста, но не
гарантирует правильную интерпретацию. Подробности текущей работы — в WORK_LOG.md.
