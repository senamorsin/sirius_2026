# Глоссарий

| Термин | Значение в проекте |
|---|---|
| Требование | Один проверяемый критерий с постоянным ID |
| Блок | Извлечённый абзац, строка таблицы или текст страницы с адресом |
| Фрагмент | Часть блока, помещающаяся в контекст поиска |
| Источник | Адрес исходного текста, вычисленный программой |
| Эмбеддинг | Числовой вектор для поиска близких по смыслу текстов |
| Гибридный поиск | Смысловой поиск вместе с точным совпадением обозначений |
| Доказательство | Цитата, сверенная с текстом конкретного фрагмента, и его источник |
| Соответствует | Доступные основания подтверждают требование |
| Не соответствует | Найдено явное противоречие требованию |
| Недостаточно данных | Доступного текста недостаточно для вывода |
| Техническая ошибка | Проверка не выполнена из-за сбоя, а не содержания документа |
| NLI | Классификация отношения между исходным текстом и утверждением |
| RAG | Подбор релевантных фрагментов перед обращением к языковой модели |
| Апробация | Проверка программы представителем целевой аудитории на согласованных материалах |
