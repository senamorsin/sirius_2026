# Материалы защиты

Редактируемые исходники: DOCX и PPTX; PDF — версии для просмотра. Аннотация также
экспортирована в DOC. Учебный пример и описание запуска актуализированы; генераторы
материалов удалены из рабочего проекта. Для дальнейшего редактирования используйте
исходные документы, затем экспортируйте PDF в офисном редакторе.

Перед сдачей заполнить ФИО и должности руководителей, провести репетицию, проверить
личный вклад и согласовать материалы с куратором. Апробация и экономический эффект
не заявляются без данных. График 16 ноября — 13 декабря является плановым.
Фактические действия — [журнал](../docs/WORK_LOG.md), текущий порядок приёмки —
[проверка на примере куратора](../docs/VALIDATION.md).
